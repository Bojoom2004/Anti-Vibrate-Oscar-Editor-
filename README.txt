XL-750BH/XL-747H

В чём была проблема. Устранил баг в окне «Установка стабилизатора» .  После отключения питания или перезагрузки ПК он сбрасывается, а Oscar Editor сам её обратно не включает. Теперь настройки не сбрасываться и есть файл для правки AntiVibrate.txt. В конфигах ничего исправить было нельзя: ни в шаблонах .ASC, ни в .ini этого параметра нет, он включается командой, которую программа отправляет мыши (HID-команда 0xAE00 + уровень).
Что я сделал с OscarEditor.exe (итоговая версия).
Автовключение при подключении мыши. В процедуре инициализации устройства (адрес 0x41BD6B) добавил вызов нового кода. Значения по умолчанию: Enable=1, Level=4.
Настроить стабилизатор можно как через радное окно так и через AntiVibrate.txt

Про; Настройка стабилизатора курсора (AntiVibrate) для OscarEditor.exe
; Файл должен лежать в одной папке с OscarEditor.exe. Сохраняйте как обычный текст
; Изменения применяются при следующем подключении мыши или после перезапуска программы
; (выйдите из программы через значок в трее и запустите снова, либо переподключите мышь по USB)
;
; Enable = 1  включать стабилизатор автоматически,  0 - не включать
; Level  = уровень Height число 0-31. Ниже 4 уже может не работать. Оптимально от 4 до 12.
; По умолчанию: Enable=1, Level=4.
[AntiVibrate]
Enable=1
Level=4
